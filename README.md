# Laravel AccessProof

Runtime authorization regression tests for Laravel 12 and 13.

AccessProof exercises real Laravel HTTP feature tests with explicit actors, target resources and persisted-state assertions. It is not an automated security audit or a complete authorization coverage scanner.

> Development in progress. Do not publish or treat this repository as production-stable before the CI matrix is green.
